# DeenStars

Little Steps. Beautiful Habits. Brighter Hearts.

An Islamic early-learning and habit-building iOS app for children aged 3–6, owned by a parent, built with SwiftUI and Firebase.

**Status:** planning. No application code yet. Waiting for architecture and UI direction approval.

## Start here

1. `docs/OPEN_QUESTIONS_AND_RISKS.md` for decisions that need your input.
2. `docs/ARCHITECTURE.md`, `docs/FIREBASE_SCHEMA.md`, `docs/AUTH_SECURITY.md` for the technical design.
3. `docs/WIREFRAMES.md`, `docs/USER_FLOWS.md`, `docs/DESIGN_SYSTEM.md` for the UI/UX direction.
4. `docs/ROADMAP.md` for phases.
